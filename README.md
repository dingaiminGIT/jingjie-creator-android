# 镜界创作 Android

这是根据现有 iOS 产品公开功能、真机界面和交互重新实现的 Android 原型，不包含原 iOS App 的源码，也没有绕过原 App 的会员校验。

## 当前版本（0.3.0）

- 首页、作品库入口、快速拍摄与场景卡片
- 去重后的 7 个差异化场景：运动·旅行双摄、15 秒预录、提词拍摄、现场讲解、探店测评、开箱展示、访谈对话
- 单摄拍照与不限时长录像，支持前后切换、点按对焦、变焦、补光灯、网格
- 前后双摄照片与录像真实合成，支持画中画、左右均分、上下均分
- 所有双摄布局可互换前后摄主副画面；录像中也可实时切换，不会断开文件
- 画中画可自由拖动，拖动后的位置会同步写入照片和最终 MP4
- 15 秒循环预录：保留按键前最多 15 秒并与后续录像拼接
- 机内提词器：编辑、速度调节、匀速滚动或系统语音识别跟读；跟读会把识别文本与文稿向前匹配后推进，不是按音量或时间模拟滚动
- 反向地理编码的地名、时间、指南针水印；不展示经纬度，水印直接写入成片，点击水印可刷新定位
- 录屏讲解：通过系统 MediaProjection 录制网页、课件和其他 App，并收录麦克风
- 跨 App 悬浮提词：可拖动、自动滚动、暂停和关闭
- 视频跟拍：选择本地参考视频后跨 App 悬浮播放，支持拖动、三档缩放、播放/暂停、前后 5 秒、0.5/0.75/1 倍速、循环、镜像和静音
- 图集跟拍：一次选择最多 50 张参考图，跨 App 悬浮查看，支持前后切换、完成标记、计数和三档缩放
- 前摄三档屏幕柔光（自然、暖色、冷色），后摄使用硬件补光灯

第一次使用悬浮提词或跟拍播放器时，Android 会要求“显示在其他应用上层”权限。小米系统还可能要求手动允许悬浮窗和后台弹出界面。

## 构建

要求 Android SDK 35、JDK 17。

```bash
./gradlew :app:assembleDebug
```

生成文件：`app/build/outputs/apk/debug/app-debug.apk`。

## 当前边界

- 双摄/带水印成片使用 720×1280、24fps 的稳定合成管线；普通单摄仍以 1080P 优先。双摄照片为 1080×1920 JPEG。
- 15 秒预录已实现手动触发；免手持语音口令触发仍待离线关键词模型。
- 录屏讲解已实现，首次启动必须接受 Android 系统录屏授权。
- 参考图滤镜、前景抠图、贴纸、多音轨合并待实现。

详细的功能核对与真机验证见 [RECOVERY_REPORT.md](RECOVERY_REPORT.md)。
